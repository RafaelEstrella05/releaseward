# Agent Instructions

This repo's full project methodology and context lives in `CLAUDE.md` — read it in full before doing any work here, and follow it exactly as written. It is not Claude-specific; it applies to any coding agent working in this repo, including Codex.

The single most important rule, repeated here because it must never be missed:

> **Never commit content that reveals a specific target company, hiring manager, or job application** in this repo — no mentions of specific employers/interviewers anywhere in `README.md`, `PROJECT_BRIEF.md`, `ARCHITECTURE.md`, `DECISIONS.md`, or code comments. This is a hard rule, not a style preference.
>
> - **Not allowed**: the company's name (or any near-identifiable variant), a hiring manager's/interviewer's name, a specific job posting/req ID, or anything else that would let a reader identify *which* employer this is for.

See `CLAUDE.md` for everything else: the builder workflow (one task at a time, append-only decision log, git requires approval every time, run it for real, etc.) and full project-specific context.
